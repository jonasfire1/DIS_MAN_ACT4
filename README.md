"# DIS_MAN_ACT4" 
To run the program, navigate to the folder containing the project and run:
go run .
followed by one of the following options: first_node, second_node, or third_node, with each option representing a node.
This will start the selected node.
For the system to operate correctly, all three nodes must be running simultaneously. To achieve this, run each node in a separate terminal window.
Once all three nodes are connected, the system will begin operating and log all actions performed by the node running in that terminal.
